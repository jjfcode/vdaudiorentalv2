# VD Audio Rental

Static website for VD Audio Rental, a professional audio rental company serving tours, theatres, rental houses, and live productions.

Live site: https://jjfcode.github.io/vdaudiorentalv2/

## What’s in the site

- Home, About, Contact, Our Gear, and Used Equipment pages
- Category pages for microphones, mixers, IEM, IFB, intercom, speakers, and related production gear
- Responsive navigation, quote/contact calls to action, and social links
- Brand and product image galleries for gear listings

## Project structure

- `index.html` - homepage published on GitHub Pages
- `about.html`, `ourgear.html`, `used-equipment.html`, `contact.html` - main site pages
- `css/` - page styles and shared layout styles
- `js/` - site scripts for navigation, forms, and gear filtering
- `img/` - logos, brand assets, product photos, and page artwork
- Category folders such as `Microphone/`, `Mixer/`, `IEM/`, `IFB/`, `DI/`, `intercom/`, `Outboardgear/`, `Player&Recorder/`, `Snakes/`, and `Speaker/`

## Local preview

This repository does not require a build step. Open `index.html` directly in a browser, or serve the folder with any static web server if you want local routing and asset loading to behave like GitHub Pages.

## Deployment

The published site is hosted from the `master` branch on GitHub Pages at the URL above. Update the HTML, CSS, JS, or image files in this repository and push the changes to publish.
