# Project Map

## What the site contains

This repository is a static audio rental website for VD Audio Rental.

### Main pages
- `index.html` - home page
- `about.html` - company story and background
- `ourgear.html` - gear catalog with category filters
- `used-equipment.html` - used gear listings
- `contact.html` - contact and quote request page

### Content folders
- `Microphone/` - microphone brand pages
- `Mixer/` - mixer brand pages
- `DI/` - direct box pages
- `IEM/` - in-ear monitor pages
- `IFB/` - IFB pages
- `intercom/` - intercom pages
- `Outboardgear/` - processing and outboard gear pages
- `Player&Recorder/` - player and recorder pages
- `Snakes/` - cable snake pages
- `Speaker/` - speaker pages
- `headphone/` - headphone page
- `used/` - used product detail pages

### Shared assets
- `css/` - shared and page-specific styles
- `js/` - navigation, filtering, gallery, and form scripts
- `img/` - logos, product images, and page artwork

### Entry behavior
- `index.php` only includes `index.html`, so the project behaves like a static site.
- The project is designed to publish directly from the repository, with no build step.
